REQUIREMENTS:

-- A web browser (Google Chrome, Microsoft Edge, Firefox, etc.).
-- No additional software installation is required.

HOW TO RUN THE APPLICATION
1. Locate the Cypher Cryptic project folder.
2. Open the folder.
3. Double-click the cypher.html file.
4. The application will open in your default web browser.
5. Enter a numeric encryption key.
6. Enter a message in the text area.
7. Click Encrypt to encrypt the message.
8. Click Decrypt to restore the original message.
9. Click Clear to reset the fields.
